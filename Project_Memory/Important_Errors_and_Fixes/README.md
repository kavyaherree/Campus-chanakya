# Important Errors and Fixes Directory

This directory stores critical error reports and their resolutions as specified in `Instruction.md`.

## File Naming Convention
- **Error report:** `[number]_Error_[ShortDescription].md`
  - Explain the symptom, stack trace, root cause, and threat / security implications.
- **Fix report:** `[number]_Fix_[ShortDescription].md`
  - Explain the concrete code fix, files modified, and verification steps.
